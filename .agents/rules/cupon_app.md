# معماری و فلسفه پروژه تخفیف‌یاب پیامکی هوشمند (CuponApp)

## هدف و مسئله پروژه
سامانه تفکیک هوشمند پیامک‌ها و استخراج خودکار کدهای تخفیف با Gemini 3.8 Flash و موتور پشتیبان Heuristic.
هدف حل معضل گم‌شدن کدهای تخفیف در میان پیامک‌های تبلیغاتی فراوان در ایران است.

## ارکان اصلی پروژه:
1. **تفکیک ۳ لایه پیامک‌ها:**
   - تبلیغاتی (`promotional`) -> استخراج تخفیف و افزودن به لیست کدهای فعال.
   - شخصی (`personal`) -> شماره‌های ۰۹...، ایزوله‌سازی کامل در تب پیام‌های شخصی جهت حفظ حریم خصوصی.
   - بانکی (`banking`) -> تراکنش‌ها، رمز پویا، مانده‌حساب -> نادیده‌گرفتن بدون ایجاد کوپن.

2. **اطلاعات استخراجی از هر تخفیف:**
   - برند فارسی و انگلیسی (مثل اسنپ‌فود / SnappFood)
   - دسته‌بندی و اسلاگ (`food`, `transport`, `ecommerce`, `entertainment`, `supermarket`, `other`)
   - کد تخفیف دقیق، درصد یا مبلغ ریالی/تومانی
   - شرایط و حداقل خرید (`minOrder`)
   - راه گرفتن تخفیف (`instructions`) به زبان گام‌به‌گام و شیوا
   - مهلت انقضا و وضعیت انقضا
   - سیم‌کارت دریافت‌کننده (همراه اول یا ایرانسل)
   - متن خام پیامک جهت شفافیت و بررسی

3. **موتور دوگانه (Dual Engine):**
   - هوش مصنوعی: مدل `gemini-3.8-flash` از `@google/genai` با اسکیمای پاسخ JSON ساختاریافته.
   - فال‌بک اکتشافی: تابع `analyzeSmsHeuristic` در `server.ts` در صورت نبود API Key یا خطای شبکه.

4. **وضعیت‌های کدها:**
   - فعال (`active`): در لیست اصلی قابل کپی و استفاده.
   - استفاده شد (`used`): کاربر اعلام کرده مصرف شد -> انتقال به تب آرشیو.
   - کار نمی‌کنه (`invalid`): کد باطل یا نادرست -> انتقال به تب آرشیو.
   - قابلیت بازگردانی (`handleRestore`) از آرشیو به فعال.

5. **امکانات موبایلی و PWA:**
   - PWA با مانیفست استاندارد و وب‌ورکر فعال برای نصب بدون واسطه.
   - قطعه کد کاتلین Android BroadcastReceiver برای اپلیکیشن‌های بومی اندروید.
